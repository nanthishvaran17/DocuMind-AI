# Workspace UI & Content Rules

- **No emojis**: Never use Unicode emojis or pictographs anywhere in UI components, copy, logs, comments, or documentation.
- **No decorative Sparkles / star-sparkle icons**: Do not use `Sparkles`, `WandSparkles`, or similar decorative AI-star icons in headers, badges, cards, or buttons. Use clean, purpose-specific UI icons (e.g., `Terminal`, `FileText`, `ShieldCheck`) or plain typography instead. (Functional `Star` icons for user favorites/bookmarks are allowed.)
- **Product UI showcases & feature visuals (`stageshow`)**: Whenever creating or updating hero product showcases, mocked/faux product UIs, interactive walkthrough demos, or bento feature-card visuals, follow the `stageshow` skill and reuse the kit in `apps/web/src/components/stageshow/kit/` with the product tokens in `apps/web/src/components/stageshow/documind-look.css` (deliberate edge crops, `1:1` stage sizing, compact mobile compositions, quiet `Bar` filler beside real story strings, and `poster` set to the finished result beat).
